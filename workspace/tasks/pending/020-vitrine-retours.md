# 020 — Vitrine : disciplines illustrées, valeurs, esprit du club, menu

## Pourquoi

Retours du club sur le site (2026-09-24) : le code moral sur l'accueil met trop en avant le judo ;
le yoga est présenté plus brièvement que les autres disciplines ; les disciplines manquent de
visuels ; la page « Le club » doit dire ce qu'est le club (convivial, familial, ouvert à tous).

## Quoi

- **Illustration de chaque discipline** (pictogramme vectoriel maison, couleur d'accent par
  discipline) partout où elles apparaissent : accueil, page Disciplines, horaires, tarifs.
- **Yoga** : présentation étoffée (4 paragraphes, encart « Une séance au dojo »).
- **Valeurs** sur la page Disciplines : le code moral de France Judo (judo, jujitsu, taïso) et
  les principes de vie du yoga (yamas, en mots simples) ; plus de code moral sur l'accueil ni sur
  la page « Le club ».
- **L'esprit du club** sur la page « Le club » : nouveau contenu administré (titre, introduction,
  valeurs), proposé : convivial, familial, ouvert à tous, bénévole.
- **Menu** : Accueil · Le club · Disciplines · Horaires & tarifs · Compétitions (Événements, 021) ·
  Règlement · Contact.

## Critères d'acceptation

- [ ] Chaque discipline a son illustration, sur l'accueil, la page Disciplines, les horaires et les tarifs
- [ ] L'accueil ne présente plus le code moral ; la page Disciplines présente code moral et principes du yoga
- [ ] La page « Le club » présente l'esprit du club, modifiable dans « Contenu du site »
- [ ] Le menu suit le nouvel ordre
- [ ] Utilisable à 360 px

## Revue (2026-09-24) — décisions

1. Valeurs : code moral pour judo, jujitsu et taïso ; principes de vie du yoga (5 yamas), texte
   simple **à relire par le professeur de yoga**.
2. Illustrations : dessinées pour le site (pas d'image externe ni de droits à gérer).
3. Esprit du club : contenu administré (spec 014), texte proposé, à ajuster par le club.

## Notes

- Suite des retours : « Compétitions » devient « Événements » (spec 021).
