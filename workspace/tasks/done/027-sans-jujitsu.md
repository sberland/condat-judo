# 027 — Site vitrine : retirer le jujitsu

## Pourquoi

Réponse du club au questionnaire (2026-09-30) : le jujitsu n'est plus proposé (à confirmer par le
président, la question reste ouverte au questionnaire). Il n'a d'ailleurs aucun créneau dans les
horaires 2026/2027 (spec 026).

## Quoi

- Contenu « Disciplines » sans le jujitsu : migration de données 0019 (nouvelle version dans
  l'historique) et contenu initial aligné ; l'en-tête, le pied de page, la page d'accueil et le
  titre de la page Disciplines suivent le contenu (« judo, taïso et yoga »).
- Code moral : « judo et taïso ».
- Titre et descriptions du site (`index.html`), guide d'utilisation.

## Critères d'acceptation

- [x] Le jujitsu n'apparaît plus sur le site public
- [x] Le club peut le rétablir depuis « Contenu du site » si l'activité reprend

## Revue de spec (2026-09-30)

- Gardé : le nom officiel de la fédération dans le règlement (« Fédération française de judo,
  jujitsu, kendo et disciplines associées ») et le pictogramme jujitsu (utile si le club remet la
  discipline).
